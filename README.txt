Система мониторинга доступности веб-ресурсов
Курсовой проект по МДК.02.02 «Инструментальные средства разработки»

1. Требования
   Node.js версии 18 или новее (используется встроенный fetch).
   Сторонние библиотеки не нужны, команду npm install выполнять не обязательно.

2. Состав проекта
   src/index.js     - точка входа, чтение настроек и запуск
   src/Monitor.js   - класс Monitor, список сайтов, проверки по интервалу, отчёт
   src/Site.js      - класс Site, состояние и статистика одного сайта
   src/checker.js   - функция checkUrl, HTTP-запрос с тайм-аутом
   src/Logger.js    - класс Logger, запись журнала в консоль и файл
   data/sites.json  - пример файла настроек
   tests/           - автоматические тесты (node:test)

3. Настройки (data/sites.json)
   interval  - интервал между проверками, секунды (по умолчанию 30)
   timeout   - время ожидания ответа, миллисекунды (по умолчанию 5000)
   slow      - порог медленного ответа, миллисекунды (по умолчанию 2000)
   maxFails  - сколько ошибок подряд считать недоступностью (по умолчанию 3)
   logFile   - путь к файлу журнала
   sites     - список сайтов, у каждого name и url (http:// или https://)

4. Запуск
   Постоянный мониторинг:
     npm start
   или с другим файлом настроек:
     node src/index.js путь/к/файлу.json

   Одна проверка всех сайтов с выводом отчёта:
     npm run once

   Остановка постоянного мониторинга - Ctrl+C, после неё выводится итоговая таблица.
   Журнал проверок сохраняется в logs/checks.log.

5. Тесты
     npm test
   Тесты запускают локальный HTTP-сервер и не требуют доступа в интернет.
